# PZHGP Żagań – frontend

Interfejs użytkownika aplikacji oddziału (Next.js 16, React 19, TypeScript, Tailwind CSS 4).

Opis projektu, instrukcja uruchomienia, zmienne środowiskowe i testy są w [głównym README](../README.md).

## Najważniejsze komendy

```bash
npm install              # instalacja zależności
npm run dev              # serwer deweloperski: http://localhost:3000
npm run build            # build produkcyjny
npm run lint             # ESLint
npm run typecheck        # kontrola typów TypeScript
npm run cypress:run      # testy end-to-end
```
